# Roadmap

This file includes all planned changes to the mod as of the last change.

## Compatibility

- Compatibility with engine altering mods (AJE)

- Compatibility with weapons mods (specific tagging)
  - KerbalAdvancedDefenseReborn
  - BDArmory-Extended

- Craft expansions
  - KerbalAdvancedDefenseReborn (Weapons)
  - AirplanePlus (Helicopters, Prop fighters)

- New missions
  - Recon intercept mission
  - Outpost recon missions (Waypoint, SAM & Hostile dodging)
  - Bomber destruction missions
  - Facility/Airfield sabotage missions
  - Enemy VIP missions (Destroy only VIP, not other enemies)
  - SEAD missions (SAM site ridges, River run)

  - Orbital sabotage (Stealing parts with engineer via KIS/KAS or Stock)
  - Orbital rescue (Hostile approaching owned satellite)
  - Surface outposts (Planets without oceans)
  - Surface sabotage (Stealing from rovers, landers etc.)
